# Претензия

Документ **Претензия** фиксирует жалобу, приходящую от получателя или направляемую поставщику.  

Использование претензий в системе определяется настройкой **Использовать претензии** в настройках исполнения заказов.  

Претензии находятся в подсистеме **Заказы** - **Обработка заказов клиентов**.

В системе доступно создание претензий для следующих получателей:     
- [Претензии клиента](../CustomerOrders/Pretension/Pretension.md);   
- [Претензии комиссионера](../Commission/Pretension/Pretension.md);   
- [Претензии склада](../../Warehouse/MovingProducts/Pretension/Pretension.md);   
- [Претензия поставщику](../../Purchases/Pretension/Pretension.md).
