# АРМ Возврат и корректировка накладных

Для отслеживания состояний накладных в системе, а также быстрой работы с ними в системе предусмотрена обработка **"Возврат и корректировка накладных"**, которая расположена в разделе **"Заказы"** в подсистеме **"Обработка заказов клиентов"**. 

![1]

В АРМе возможен следующий функционал:  
- [Изменение состояний накладных](../../FormationOfShipments/FormationOfTheAccompanyingDocuments/OriginalDocsStatus/OriginalDocsStatus.md);  
- Корректировка накладных.

# Корректировка накладных

Под словом "Накладные" подразумеваются:  
- Реализация товаров;  
- Передача товаров на комиссию;  
- Перемещение товаров;  
- Внутреннее потребление.

После открытия обработки заполняются настройки формирования накладных.

Затем нажимаем кнопку **"Обновить"**, на форме будут выведены **"Задания на доставку"**, по которым есть накладные в соответствии с отборами.

[![18][18]][18]

Выбираем накладную, по которой будет создаваться корректировка и нажимаем кнопку **"Скорректировать"**. Откроется форма корректировки документа, на которой выбираем вид корректировки:

- Корректировка первичной накладной. При нажатии на кнопку Скорректировать изменения передаются в документ-основание.  
- Корректировка по соглашению сторон. При нажатии на кнопку Скорректировать создается документ Корректировка реализации товаров с видом Корректировка по соглашению сторон.   
- Корректировка с исправлением ошибок. При нажатии на кнопку Скорректировать создается документ Корректировка реализации товаров с видом Исправление ошибок. 

Можно изменить дату создания корректировки реализации.  

Для товаров, которые не требуют обратной доставки необходимо:  
- Поставить признак "Без возврата";  
- Указать способ оформления расхождений.  

Затем заполняем поля факт для строк номенклатуры, по которым необходимы корректировки, и указываем причину корректировки (создаются в справочнике **"Причины корректировок документов"**).

!!! attention ""  
    Создание корректировки реализации возможно только для Реализации товаров, для всех остальных накладных возможна только корректировка первичной накладной.
