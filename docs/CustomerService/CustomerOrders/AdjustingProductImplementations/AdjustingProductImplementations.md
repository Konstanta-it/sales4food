# Корректировка реализации товаров

Для внесения изменений в реализацию товаров в системе используется документ **Корректировка реализации товаров**. Документ расположен в разделе **"Заказы"**.

**Вкладка "Основное"**

Корректировка реализации заполняется по накладной. На вкладке Основное заполняются основные данные по контрагенту, все реквизиты заполняются автоматически и не доступны для редактирования.  

Указывается вид корректировки:  
- Исправление ошибок. Используется для указания расхождений, не связанных с количеством или ценой. В итоге формируется документ счет-фактура исправительный.  
- Корректировка по соглашению сторон. Используется для указания расхождений, связанных с количеством или ценой. В итоге формируется документ счет-фактура исправительный.   

**Вкладка "Товары"**

Автоматически заполняется товарами из основания, доступно добавление новых строк.  

Кнопка **Заполнить** - **по основанию** перезаполняет табличную часть по основанию.

**Вкладка "Расхождения"**

Автоматически заполняется разностью между вкладками Товары в документе и в документе-основании. Не доступна для редактирования.  

Вручную на вкладке Расхождения указываются :  
- Причина расхождения;  
- Признак Без возврата (доступна для расхождений в меньшую сторону).  

**Вкладка "Дополнительно"**

- Признак возврата многооборотной тары (определяет будет ли стоимость многооборотной тары участвовать в стоимости продажи и взаиморасчетах);   
- Способ создания;  
- Ответственный;  
- Вариант оформления расхождений (без возврата): Не учитывать остатки, Автоматическая корректировка;  
- Статья затрат (видно, когда используется автоматическая корректировка);  
- Аналитика затрат (видно, когда используется автоматическая корректировка).  

!!! attention ""   
    Вариант оформления расхождений и статья затрат заполняются автоматически из соответствующих настроек в настройках исполнения заказов. Если константы пустые, то подставляется вариант Не учитывать остатки.

# Оформление расхождений без возврата  

Все строки, которые имеют расхождение в меньшую сторону потенциально должны быть доставлены от грузополучателя обратно на склад. Но не всегда это действительно нужно. Для таких случаев в строках ставится признак Без возврата и указывается вариант оформления расхождений.

Вариант Не учитывать остатки. При таком варианте оформления расхождений строки, которые не будут доставлены обратно, не будут приняты к оформлению излишков и недостач.  

Вариант Автоматическая корректировка. При таком варианте оформления расхождений для строк, которые не будут доставлены обратно, создаются документы Распоряжение на приемку и списание товаров. В таком случае обязательно указать статью затрат (списания) и возможно указание аналитики затрат.
