# Заказ клиента  

Документ **"Заказ клиента"** отражает потребность клиента на поставку ему товаров. Документы расположены в разделе **"Заказы"**.

[![1][1]][1]

!!! attention ""  

    Для пользователей, которые занимаются созданием заказов клиентов в системе создан поставляемый профиль доступа "Создание заказов клиента".  

    В данном профиле нет роли "Разрешено изменять цены в документах", которая позволяет вручную изменять цены в заказе на отличные от установленных по соглашению.  

При создании документа автоматически подставляются статус документа и этап (если используется в системе).

На вкладке **"Основное"** указываются:

- **Номер документа** (заполняется автоматически)
- **Дата** (дата создания документа в системе)
- **Операция** - Реализация клиенту (видна, если в системе используется комиссионная торговля)  
- **Организация** (видна, если в системе несколько организаций. Заполняется автоматически, если указана основная организация)
- Подразделение (заполняется автоматически, если указано основное подразделение)
- Холдинг. Указывается, если необходимо отобрать контрагентов для выбора, иначе автоматически заполняется из карточки контрагента
- **Контрагент** (покупатель)
- **Соглашение об условиях продаж**
- Бизнес-регион (заполняется автоматически из соглашения или точки доставки)
- **Точка доставки** 
- **Тип доставки** Самовывоз, Доставка сторонней транспортной компанией, Доставка нашей транспортной компанией. Заполняется из точки доставки, можно заполнить вручную  
- **Склад отгрузки** заполняется из точки доставки, можно заполнить вручную (виден, если в системе заказ возможен только с одного склада, иначе указывается на вкладке Товары)
- Информация о ценовых условиях (момент определения цены, вид цены продажи, признак включения НДС в вид цены, налогообложение) заполняется из соглашения
- Информация о дате отгрузки и дате и времени доставки.  
Даты рассчитываются автоматически при заполнении одной из них с учетом количества дней доставки, указанного в точке доставки.   
Время доставки заполняется из точки доставки, можно заполнить вручную 

![2]

**Вкладка "Товары"**

На вкладке Товары указывается список заказываемой номенклатуры.  
Заполняются номенклатура, её характеристика, количество упаковок, упаковка (колонка Ед.).   
Цены рассчитываются автоматически из условий соглашения об условиях продаж.

По кнопке "Заполнить" - "Склад отгрузки" для выделенных строк можно заполнить склад отгрузки.  
*Кнопка доступна, когда в системе есть возможность создавать один заказ с разных складов отгрузки.* 

По кнопке "Обновить цены" - "По условиям продаж" подставляется актуальная цена по виду цен, указанному в соглашении.    
По кнопке "Обновить цены" - "По виду цен" подставляется актуальная цена по выбранному виду цен (вид цены на вкладке "Основное" поменяется на выбранный вид цены).    
По кнопке "Обновить цены" - "По ценам EDI" подставляется цена из колонки Цена EDI.  
*Кнопки доступны, если пользователю разрешено редактирование цен в заказах.*   
*Кнопка "По ценам EDI" доступна, если активна настройка [Включен EDI](../../EDM/Settings/Settings.md) и заказ загружен из EDI.*  

![3]

В нижней части формы документа заполняется комментарий, рассчитываются: процент скидки, сумма скидки, сумма НДС, итоговая сумма заказа, итоговый вес заказа.

**Вкладка "Печать"**

На вкладке Печать автоматически заполняется информация, которая будет использоваться в печатных формах. Все поля доступны для редактирования.

![4]

Для документа **"Заказ клиента"** используются печатные формы: *"Заказ клиента"*, *"Счет на оплату (выводить скидки)"*, *"Счет на оплату (не выводить скидки)"*.

![6]

**Вкладка "Дополнительно"**  

На вкладке Дополнительно автоматически заполняется способ создания заказа и ответственный (пользователь, который создал заказ в системе)  

Можно указать входящие номер и дату заказа
