# Регламентные задания

**Контур ЭДО: Актуализация состояний счет-фактур**. Регламентное состояние, которое будет актуализировать состояния счет-фактур за определенный период. Период по умолчанию последние 30 дней, но может быть изменен в [реестре](../../Settings/SettingsRegistry.md).

**Контур ЭДО: Отправка счет-фактур**. Регламентное состояние, которое будет отправлять счет-фактуры без подписи (как черновики) за определенный период. Период по умолчанию последние 30 дней, но может быть изменен в [реестре](../../Settings/SettingsRegistry.md).

*Оба регламентных задания работают по принципу подключения по служебным логину и паролю, поэтому необходимо заполнить эти данные в обработке Диадок для их корректной работы.*
