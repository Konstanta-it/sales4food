В ERP4FOOD на вкладке настроек документов можно увидеть только корректировочные и первичные документы. 

При этом стоит отметить, что старые форматы отправки (те, что были до ФНС 970 и ФНС 736) не были реализованы, поэтому при их выборе отправить документы не получится. Текущие форматы **ФНС 970 и ФНС 736** являются актуальными, и отправка документа в старом формате диадоком все равно обрабатываться уже не будет, хотя в модуле пока и осталась возможность выбора (на последней тестируемой версии).

[![1][1]][1]

При выборе Первичных документов можно выбрать три варианта вида отправки пакета:

1.	УПД
2.	СФ + Торг12
3.	УПД СЧФ + УПД ДОП

По умолчанию будет стоять УПД.

[![2][2]][2]

При выборе Корректировочных документов можно выбрать три варианта вида отправки пакета:

1.	УКД
2.	УКД КСЧФ + УКД ДИС
3.	КСФ

По умолчанию будет стоять УКД.

[![3][3]][3]

| Документы | Что входит в пакет | Описание |
| ------- | ------- | ------- |
| Первичные документы | УПД | УПД, включающий в себя первичный документ и счет- фактуру |
|  | СФ + Торг12 | Счет-фактура и товарная накладная |
|  | УПД СЧФ + УПД ДОП | УПД, включающий в себя первичный документ и счет- фактуру, но на отправку такой пакет сформируется раздельными документами. |
| Корректировочные документы | УКД | УКД, включающий в себя корректировочный документ и корректировочный счет-фактуру |
|  | УКД КСЧФ + УКД ДИС | УКД, включающий в себя корректировочный документ (УКД ДИС) и корректировочный счет-фактуру (УКД КСЧФ), но на отправку такой пакет сформируется раздельными документами. |
|  | КСФ | Корректировочный счет-фактура |

Текущие настройки можно производить как по всей организации, так и отдельно по контрагенту. В диадоке контрагент тоже является организацией, поэтому разницы в вводе настроек нет.

Остальные настройки отрабатывают согласно общей справке Контур ЭДО (Диадок).
