# Формирование пакета

Исходя из настроек документов происходит формирование пакета к отправке. В нем может быть от одного до двух документов, у каждого из которых можно посмотреть печатную форму.

1.	Если выбраны документы к отправке **УПД**/**УКД**, то пакет состоит только из этих документов:

[![1][1]][1]

[![2][2]][2]

2. Если выбраны к отправке **УПД СЧФ + УПД ДОП**/**УКД КСЧФ + УКД ДИС**, то пакет будет состоять из двух документов. Это не будет о относиться лишь к счет-фактуре комиссионера, там в любом случае будет сформирован один документ (**УПД СЧФ**/**УКД КСЧФ**):

[![3][3]][3]

[![4][4]][4]

3. Если выбран к отправке **СФ + ТОРГ 12**, пакет будет состоять из двух документов:

[![5][5]][5]

4.	Если выбран к отправке **КСФ**, пакет будет состоять из одного документа - корректировки:

[![6][6]][6]
