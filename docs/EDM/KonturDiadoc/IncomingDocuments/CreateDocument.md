# Создание документа на основании электронного

Исходя из правил сопоставления документы 1С можно создать из электронного документа (входящего). 

1. **Поступление товаров**

Заполняется либо по заказу на поставщику, либо (если заказа не находит) просто по электронному документу. Во втором случае документ не будет проведен, потому что в электронном документе не хватает данных для заполнения документа 1С.

Заказ поставщику ищется по ключу *«номер_заказа»* в дополнительной информации по следующим праметрам: Номер (номер_заказа), Дата (от даты документа – год), Организация и Поставщик. Соответственно, ищется не помеченный на удаление документ.

Заполняются номер и дата входящие. Способ создания = Загрузка из EDI.

Если включена настройка *«Использовать дату электронного документа»*, то встает дата в поступлении как во входящем документе, если нет – текущая дата. Также если включена настройка создания счет-фактур, то создастся счет-фактура.

2. **Корректировка поступления**

Для корректировки предварительно ищется документ-основание (поступление). Документ ищется по номеру и дате из тэга *СвКСчФ.СчФ* (для УКД) или *СвСчФакт* (для иУПД), а также по организации и поставщику. Ищется не помеченный на удаление документ. Если документ основание не найден, то будет выведена ошибка.

Заполняется корректировка поступления по документу-основанию с учетом данных из электронного входящего документа. Заполняются номер и дата входящие. Способ создания = Загрузка из EDI.

Если включена настройка *«Использовать дату электронного документа»*, то встает дата в корректировке как во входящем документе, если нет – текущая дата. Также если включена настройка создания счет-фактур, то создастся счет-фактура.

3. **Счет фактура полученный**

Заполняется по документу-основанию, исходя из данных в xml в *ДокПодтвОтгрНом*: номера и даты документа отгрузки.

Заполняются номер и дата входящие. Способ создания = Загрузка из EDI.

Если включена настройка *«Использовать дату электронного документа»*, то встает дата в поступлении как во входящем документе, если нет – текущая дата.
