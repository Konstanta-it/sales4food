# Сопоставление номнклатуры

В типовом модуле для сопоставления используется регистр сведений **Номенклатура контрагентов БЭД**. Сопоставление происходит по идентификатору и владельцу (контрагенту). 

Если по этим соответствиям находится номенклатура, то в форме создания документа эта информация отразится. Если же будут проблемы, то будет прописано сколько номенклатур уже сопоставлено и дана возможность посмотреть и отредактировать эти сопоставления. 

[![1][1]][1]

При просмотре и редактировании сопоставления номенклатура из 1С может подставиться автоматически, если будет найдена по коду/артикулу из электронного документа. В таком случае достаточно будет нажать на кнопку сохранить, чтобы в дальнейшем ее не указывать.
