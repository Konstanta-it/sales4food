# Использование ЭДО в системе

Для того чтобы использовать встроенные возможности ЭДО в системе, необходимо включить их  
- Настройки исполнения заказов в подсистеме Заказы имеют настройку Включен EDI, по которой становятся доступными :   
    - справочник [Настройки по организации](OrganizationSettings.md);  
    - справочник [Настройки по контрагенту](CounterpartiesSettings.md);  
    - регистр [Общий журнал EDI](StatusLog.md);   
    - справочник [Реестр настроек](SettingsRegistry.md);  
    - константа Настройка подписания по умолчанию;   
    - АРМ Отправка и подписания документов;  
    - состояния документов в списках и формах документов, АРМах;  
    - возможность обновлять цены в заказах по ценам EDI;  
    - отчеты.  
- Настройки склада и доставки в подсистеме Склад и доставка имеют настройку Использовать транспортный документооборот, по которой становятся доступными :  
    - константа Настройка подписания по умолчанию;   
    - справочник [Реестр настроек](SettingsRegistry.md);   
    - состояния документов в списках и формах документов, АРМах;  
    - возможность формировать ЭПД в АРМах;   
    - АРМ Отправка и подписания документов.
