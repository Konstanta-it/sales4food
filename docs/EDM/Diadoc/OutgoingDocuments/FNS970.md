# Заполнение исходящего документа ФНС-970

Сбор данных происходит либо по счет-фактуре, либо по одному из документов-основания (если функция УПД ДОП): 

- реализация
- корректировка  
- счет-фактура выданный (аванс)  
- передача между организациями напрямую  

[В справке Диадока](https://developer.kontur.ru/Docs/Diadoc_UM/objects/970%40/UTD970SellerContent.html) предоставлено описание структуры и тэги, которые будут исходя из нее заполнены. В подключаемом модуле заполняется данная структура, а по ней уже заполняется само сообщение xml типовыми методами. 

Подробнее о заполнении [здесь](https://docs.google.com/spreadsheets/d/1685lg8jQHeEcFbOAG5QccxZxL3GUTIoPXoqnuhck_Qs/edit?gid=463561086#gid=463561086) (вкладка ФНС 970)
