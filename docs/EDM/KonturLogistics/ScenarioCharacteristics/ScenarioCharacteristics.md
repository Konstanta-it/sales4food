# Особенности сценариев

**Формирование Заказ заявка Титул 1**  

Формирование документа ЭПД Заказ заявка Титул 1 доступно в АРМе [Рабочее место менеджера по доставке](../../../CustomerService/PlanningOfShipments/DistributionOfShipmentsByCar.md) при нажатии на кнопку Сформировать ЭПД. Документ сформируется для Заданий на доставку (при наличии нужной конвертации документов), у которых заполнен реквизит Перевозчик.

**Формирование Транспортная накладная Титул 1**  

Формирование документа ЭПД Транспортная накладная Титул 1 доступно в АРМе [Формирование накладных](../../../CustomerService/FormationOfShipments/FormationOfTheAccompanyingDocuments/FormationOfTheImplementationsOfProducts.md) при нажатии на кнопку Сформировать ЭПД. Документ сформируется для накладных (при наличии нужной конвертации документов), у которых в заказе тип доставки - Сторонней транспортной компанией.

**Отслеживание состояний Транспортных накладных**  

В АРМе [Возврат и корректировка накладных](../../../CustomerService/FormationOfAFeedback/AdjustingProductImplementations/AdjustingProductImplementations.md) выводится состояние текущего титула транспортной накладной.
