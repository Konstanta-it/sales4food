# Подключение ПМ

**Техническая часть**

1.	Установите модуль в выбранной поставке (подсистема). Подробную инструкция смотреть в официальной [документации](https://disk.skbkontur.ru/index.php/s/XQFXtGWKgmLety6?dir=/&editing=false&openfile=true).
2.	Произведите настройку подсистемы. Подробную инструкция смотреть в документации в разделе «Установка модуля» (Настройка определяемых типов, Настройка общих команд)/
3.	Произведите настройку для нашей подсистемы к2Логистика.
4.	Добавьте нужные объекты в определяемые типы: 
    - ЭлектронныеПеревозочныеДокументы - документы внедряемой подсистемы, которые будут использоваться для ЭТрН.  
    - УчетныеДокументыЛогистики - документы нашей системы, на основании которых будут формироваться ЭТрН.  
5.	Добавьте РегистрСведенийНаборЗаписей.КонтурЛогистика_СтатусыТитулов в подписку на событие.

**Пользовательская часть**

1. Запустите модуль и выполните авторизацию в сервисах Контур.Логистика и Контур.Диадок.
2. Выполните первоначальные настройки с помощью стартового помощника.  
3. С помощью обработки «Выгрузка и загрузка настроек (Контур.Логистика)» загрузите готовые настройки конвертации от департамента разработки или создайте свои.
4. Выполните настройки подписания.
