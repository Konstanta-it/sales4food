# Регламентные задания

**Контур EDI: Обмен с сервером**. Регламентное задание, которое будет совершать обмен с сервером за определенный период (загружать, создавать, выгружать и подписывать документы). Период по умолчанию последние 30 дней, но может быть изменен в [реестре](../../Settings/SettingsRegistry.md).

Помимо обычного функционала по загрузке и выгрузке РЗ по Контуру также будет создавать документы (заказы и претензии / акты) и обновлять заказы по новым версиям, если они еще в статусе, при котором не формируется план отгрузки.
