# Автоматическое сопоставление документов

Документ автоматически ищется по следующим параметрам отбора:

1.	Организация 
2.	Поставщик
3.	Дата накладной (поступление / корректировка) / Дата входящий (счет фактура полученный)
4.	Номер накладной (поступление / корректировка) / Номер входящий (счет фактура полученный)
