# Подключение ПМ

При открытии Диадока любым способом (расширение или внешняя обработка) в первую очередь, так как конфигурация ERP4FOOD не поддерживается данным модулем, будет выведено соответствующее окно:

[![1][1]][1]

Здесь нужно выбрать вкладку **Пользовательский модуль**, местонахождение подключаемого модуля – **В составе конфигурации**, имя обработки – **к2ПодключаемыйМодульКонтурЭДО**. Далее необходимо нажать на кнопку сохранить. 

Эту настройку понадобится сделать лишь один раз при первом запуске модуля.

[![2][2]][2]

После сохранения будет предложено перезапустить модуль. Это обязательно для корректной работы:

[![3][3]][3]

Если ранее модуль уже запускался в базе и были применены иные настройки, то для начала нужно их удалить. Диадок пишет свои настройки в рс **Дополнительные сведения**. В РС нужно будет удалить само значение в соответствующей настройке по ключу:

[![4][4]][4]

Результатом того, что подключаемый модуль успешно загрузился, будет открытие обработки без ошибок:

[![5][5]][5]
