# Вывод исходящих документов

На вкладке **Для отправки** выводится список исходящих документов с соответствующими отборами.

[![1][1]][1]

Вывод документов здесь переопределен, но логика работы сохранена. Исходящие пакеты формируются по документам **Счет-фактура выданный**. Чтобы документ появился к отправке, нужно чтобы были соблюдены следующие условия:

1.	Счет-фактуры должны быть под пользователем доступны хотя бы к чтению
2.	Счет-фактуры должны быть по тем контрагентам и реализациям, которые настроены в модуле Диадок
3.	Вид пакета счет-фактуры должен быть выбран в настройках документов (по организации и/или по контрагенту)
4.	Для вывода непроведенных счет-фактур должна быть включена настройка **Отправлять непроведенные**, в ином случае счет-фактура должна быть проведена. Помеченные на удаление счет-фактуры в модуле не выводятся
5.	Счет-фактура не должна быть уже отправлена. Такие документы выводятся на соседней вкладке **Исходящие**
6.	У счет-фактуры должен быть документ-основание
