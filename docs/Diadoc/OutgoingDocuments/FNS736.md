# Заполнение исходящего документа ФНС-736

Сбор данных происходит либо по счет-фактуре, либо по корректировке напрямую (если функция ДИС). 

[В справке Диадока](https://developer.kontur.ru/Docs/Diadoc_UM/objects/736%40/UcdSellerContent.html) предоставлено описание структуры и тэги, которые будут исходя из нее заполнены. В подключаемом модуле заполняется данная структура, а по ней уже заполняется само сообщение xml типовыми методами. 

Подробнее о заполнении [здесь](https://docs.google.com/spreadsheets/d/1685lg8jQHeEcFbOAG5QccxZxL3GUTIoPXoqnuhck_Qs/edit?gid=463561086#gid=463561086) (вкладка ФНС 736)
